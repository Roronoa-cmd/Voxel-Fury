Yahan apni gun sound files rakho (optional). Naam bilkul aise hone chahiye:
ak, sc, sn, sm, sg, lm, dm, dg, pi, ar, kn, kt   (.mp3 ya .ogg ya .wav)
  ak=AK-47  sc=SCAR-H  sn=Sniper  sm=SMG  sg=Shotgun  lm=LMG
  dm=DMR  dg=Desert Eagle  pi=Revolver  ar=Assault Rifle  kn=Knife  kt=Katana
File na ho to game built-in (code se bani) awaaz use karta hai.
Note: file:// se kholne par browser in files ko block kar sakta hai - local server se chalao.

Extra effects: rl.wav = reload; flyby.wav = enemy bullet passing close by.
